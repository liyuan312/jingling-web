# 🥚 精灵传说 · 网页版

一款基于「宝可梦收集 + 挂机」玩法的独立小游戏网页版，包含 **Gen1-5 全 649 只宝可梦**、18 属性槽、品质系统（普通/稀有/史诗/传说/神话）、战力(CP)与经验升级、爬塔对战、自动孵化/自动推关、全图鉴收集。

> 网页版为纯前端实现（HTML + CSS + Canvas + JS），**无后端、无数据库**。每位访客打开即是一个**全新账号**，刷新页面即重置，数据不会留存任何服务器。

---

## ✨ 玩法亮点

| 系统 | 说明 |
|---|---|
| 🥚 精灵蛋孵化 | 点击中央凤王精灵蛋消耗精灵球孵化，品质越高越稀有 |
| ⚡ 自动孵化 | 能量满自动孵化，可切换 1x / 2x / 3x / 5x / 10x 速度 |
| 🌟 大师球 | 通关每 10 层塔获得，必出当前最高品质（右上角一键投掷） |
| ⚔️ 爬塔对战 | 越往上敌人越强，每 10 层一只精英怪，自动推关永不停歇 |
| 📋 精灵详情 | 属性页点击任意精灵查看完整六围、GO 三围、招式与战力 |
| 📖 全图鉴 | 收集 649 只，解锁首次发现奖励 |
| 🎨 纯 CSS 场景 | 天空/云朵/远山/草地全部由 CSS 绘制，无照片无干扰，精灵显示清晰 |

所有数值公式与 Python 桌面版（pygame）**1:1 一致**，并通过自动化测试逐项校验（品质、CP、HP、招式、属性克制、完整界面流程）。

## 🌐 生成在线链接（GitHub Pages）

> 你需要一个 **GitHub 账号**。以下两种方式任选其一，之后就能得到形如 `https://你的用户名.github.io/精灵传说网页版/` 的公开链接，把这个链接放进简历即可，点开即全新账号。

### 方式 A：网页上传（无需安装 git，推荐新手）

1. 打开 [github.com/new](https://github.com/new)，仓库名填 `精灵传说网页版`，勾选 **Public**，点 **Create repository**。
2. 进入新仓库页面，点 **uploading an existing file**（上传现有文件）。
3. 把本文件夹里的这 4 个文件拖进去：
   `index.html`、`pokemon_data.js`、`pokemon_moves.js`、`pokemon_sprites.js`
4. 点 **Commit changes** 提交。
5. 进入仓库 **Settings → Pages**，Source 选 `Deploy from a branch`，分支选 `main`，目录选 `/ (root)`，点 **Save**。
6. 等约 1 分钟，页面顶部会出现绿色提示 **"Your site is live at https://你的用户名.github.io/精灵传说网页版/"**。

### 方式 B：git 命令行

```bash
# 先安装 git，然后：
cd 精灵传说网页版
git init
git add .
git commit -m "精灵传说网页版"
git branch -M main
git remote add origin https://github.com/你的用户名/精灵传说网页版.git
git push -u origin main
# 再去 Settings → Pages，Source 选 Deploy from a branch → main → Save
```

### 刷新链接

在线链接更新内容后：Settings → Pages 页面右下角有 **Custom domain** 下的部署记录，可点重新部署；或重新 push 一次即可自动更新。
